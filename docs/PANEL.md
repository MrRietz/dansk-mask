# Weapon panel (Worms Armageddon layout)

`panel: [column, row]`. Columns are the F-keys (F1 = column 0 ... F12 = column 11); pressing an F-key
cycles through the usable weapons in that column. Rows 0–5. Slots marked ✔ already exist.

(e.g. `homing` = "Homing Missile", `pigeon` = "Homing Pigeon", `axe` = "Battle Axe", `suicide` = "Suicide Bomber",

`mbbomb` = "MB Bomb", `salvation` = "Salvation Army", `oldwoman` = "Old Woman", `scales` = "Scales of Justice").
